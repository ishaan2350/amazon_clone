# Amazon Clone

A simple Amazon homepage clone built using HTML and CSS.  
This project recreates the basic UI design of Amazon to practice frontend web development skills.

---

## 🚀 Features

- Amazon-inspired homepage UI
- Responsive navigation bar
- Product sections and layout
- Clean and modern design
- Pure HTML & CSS implementation

---

## 🛠️ Tech Stack

- HTML5
- CSS3
